# رِعاية — نظام إدارة الحضانة

واجهة عربية RTL لإدارة سجلات حضانة الأطفال، مبنية بـ HTML وCSS وJavaScript دون تثبيت حزم.

## التشغيل
افتح `index.html` في متصفح حديث.

## الملفات
- `index.html`: هيكل التطبيق.
- `styles.css`: التصميم المتجاوب.
- `app.js`: إدارة السجلات والحضور والمدفوعات والتقارير.

## الميزات
- لوحة تحكم ومؤشرات مختصرة.
- إضافة وتعديل وحذف سجلات الأطفال والمربّيات والمدفوعات.
- البحث والتصفية وتصدير CSV.
- تسجيل الحضور اليومي مع الحالة ووقت الوصول.
- واجهة عربية متجاوبة مع الهواتف.

## ملاحظة أمنية
هذه نسخة Frontend تجريبية تحفظ البيانات في `localStorage` على المتصفح الحالي فقط. لا يوجد خادم أو تسجيل دخول أو مزامنة أو نسخ احتياطي. لا تدخل بيانات شخصية حقيقية للأطفال قبل إضافة Backend وقاعدة بيانات ومصادقة وصلاحيات وحماية مناسبة.
