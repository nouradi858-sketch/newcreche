# رعاية — إدارة الحضانة

واجهة عربية RTL ولوحة الإدارة، مع بداية خادم PHP للمصادقة والصلاحيات وبوابة الأولياء.

## الحالة الحالية

- `login.html`: صفحة دخول تتصل بخادم PHP.
- `accounts.html`: واجهة الإدارة لإنشاء حسابات الأولياء والمربّيات وربط ملفات الأطفال بحساب الولي.
- `backend/api.php`: جلسات دخول، كلمات مرور مجزأة، إنشاء حساب الإدارة لأول مرة، إنشاء حسابات الأولياء/المربّيات، وربط ملفات الأطفال بحساب الولي.
- `parent.html`: بوابة الولي التي تعرض الأطفال والمدفوعات المسموح بها لحسابه فقط.
- `auth-guard.js`: يتحقق من جلسة الإدارة قبل إظهار لوحة الإدارة.
- `index.html`, `styles.css`, `app.js`: واجهة لوحة الإدارة الحالية.

**تنبيه مهم:** هذه ليست خدمة منشورة بعد. ملفات PHP لا تعمل على GitHub Pages، كما أن عمليات لوحة الإدارة القديمة (الإضافة والتعديل والحذف) لم تُربط كلها بعد بقاعدة البيانات؛ لا تعتبر النظام جاهزًا للاستخدام الفعلي أو لإدخال بيانات أطفال حقيقية قبل استكمال الربط والاختبارات.

## التشغيل المحلي

المتطلبات: PHP 8+ مع إضافتي PDO وPDO SQLite، وخادم ويب يدعم PHP. لا تفتح الملفات مباشرة من `file://` ولا تستخدم GitHub Pages لتشغيل الـ API.

1. اضبط متغير البيئة `CRECHE_SETUP_TOKEN` على قيمة عشوائية طويلة (24 حرفًا على الأقل).
2. اضبط `CRECHE_DB_PATH` على مسار قاعدة بيانات خارج مجلد `public`/المجلد القابل للوصول عبر الويب، مع صلاحيات قراءة/كتابة مناسبة.
3. شغّل الموقع وخادم PHP على نفس الأصل (same origin)، مع توجيه طلبات `backend/api.php` إلى PHP.
4. أرسل طلب POST إلى `backend/api.php?action=setup` مع JSON يحوي `setup_token`, `name`, `email`, `password` لإنشاء حساب الإدارة الأول مرة واحدة. كلمة المرور لا تقل عن 12 حرفًا. احذف `CRECHE_SETUP_TOKEN` بعد الإعداد.
5. سجّل الدخول من `login.html`. أنشئ حسابات الأولياء/المربّيات من خلال طلب POST مصادق عليه إلى `backend/api.php?action=users`، مع ترويسة `X-CSRF-Token` التي يعيدها مسار `me` أو `login`.

## نقاط أمنية

- لا توجد حسابات افتراضية ولا كلمات مرور ثابتة في المستودع.
- صلاحيات API تتحقق على الخادم؛ الولي لا يستطيع طلب سجلات الأطفال أو المدفوعات الخاصة بولي آخر.
- استخدم HTTPS في الإنتاج، وحدّد صلاحيات ملفات قاعدة البيانات، وفعّل النسخ الاحتياطي، وحدّث الاعتماديات.
- لا ترفع صور الأطفال أو إيصالات الدفع أو ملفات `.env` أو قاعدة البيانات إلى GitHub.
- يجب استكمال ربط لوحة الإدارة بعمليات API وإضافة اختبارات تلقائية قبل الاستخدام الإنتاجي.
