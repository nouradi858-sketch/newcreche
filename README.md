# Riaya — نظام إدارة الحضانة

مشروع واجهة عربية RTL لإدارة حضانة الأطفال.

## محتويات المشروع
سيتم إرفاق الحزمة المضغوطة `riaya-creche-management.zip` في هذا المستودع. فك الضغط للحصول على `index.html` و`styles.css` و`app.js` و`README.md`.

## التشغيل
افتح `index.html` في متصفح حديث. لا يلزم تثبيت حزم.

## الميزات
- إدارة الأطفال والمربيات.
- تسجيل الحضور اليومي.
- متابعة الاشتراكات والمدفوعات.
- تقارير وتصدير CSV.
- واجهة عربية متجاوبة.

## تنبيه
هذه نسخة Frontend تجريبية تحفظ البيانات في `localStorage` على الجهاز الحالي. لا تستخدم بيانات حقيقية للأطفال قبل إضافة خادم آمن ومصادقة وصلاحيات وقاعدة بيانات ونسخ احتياطي.
